# ⚙️ Dossier Core

### 💡 C'est quoi ?
C'est le moteur et le système nerveux du projet. C'est ici que se trouvent les règles du jeu et la mémoire partagée.

### ❌ Le problème
Si on a plusieurs agents, comment savent-ils quand c'est à leur tour de travailler ? Comment se passent-ils les informations (le rapport, les recherches) sans les perdre ?

### ✅ La solution
- **LangGraph Orchestrator** : Un chef d'orchestre qui dit "Toi d'abord, ensuite toi".
- **State** : Une mémoire commune (comme un tableau blanc) où tout le monde écrit ses résultats pour que les autres puissent les lire.
- **Logger** : Un journal de bord qui note tout ce qui se passe pour qu'on puisse vérifier après.

# 🖥️ Dossier UI (User Interface)

### 💡 C'est quoi ?
C'est la partie visible de l'iceberg. C'est l'écran que l'utilisateur voit pour interagir avec l'assistant.

### ❌ Le problème
Lancer des scripts Python dans un terminal noir avec du texte qui défile, c'est compliqué et ça fait peur aux utilisateurs normaux. On ne voit pas bien ce qui se passe.

### ✅ La solution
Une belle interface web (avec Streamlit) :
- Un champ texte simple pour donner sa mission.
- Une barre de progression pour voir les agents travailler en direct.
- Un bouton pour télécharger le résultat final.
C'est simple, visuel et rassurant.

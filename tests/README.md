# 🧪 Dossier Tests

### 💡 C'est quoi ?
C'est le laboratoire de contrôle qualité. Ici, on vérifie que tout fonctionne comme prévu avant de lancer le système.

### ❌ Le problème
Quand on modifie le code d'un agent ou d'un outil, on risque de casser quelque chose qui marchait avant sans s'en rendre compte (régression).

### ✅ La solution
Des scripts automatiques qui lancent les agents et les outils dans des situations précises pour vérifier qu'ils répondent correctement. Si un test échoue, on sait tout de suite qu'il y a un bug à corriger.

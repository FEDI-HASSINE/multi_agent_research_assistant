# 🛠️ Dossier Tools

### 💡 C'est quoi ?
C'est la boîte à outils des agents. Ce sont les "mains" du système qui permettent d'agir concrètement.

### ❌ Le problème
Une IA (LLM) est juste un cerveau dans une boîte. Elle peut penser, mais elle ne peut pas aller sur Google, lire un PDF ou sauvegarder un fichier toute seule.

### ✅ La solution
On crée des fonctions Python spécifiques que les agents peuvent "appeler" :
- **Search Tool** : Pour simuler une recherche sur internet.
- **RAG Tool** : Pour chercher dans des documents précis.
- **PDF Export** : Pour créer un vrai fichier à la fin.

# 🤖 Dossier Agents

### 💡 C'est quoi ?
C'est ici que vivent les "cerveaux" de notre assistant. Chaque fichier représente un agent avec une personnalité et un rôle précis.

### ❌ Le problème
Demander à une seule IA de tout faire (chercher, analyser, rédiger, corriger) donne souvent des résultats moyens ou confus. C'est trop de responsabilités pour un seul modèle.

### ✅ La solution
On divise le travail !
- **Manager** : Le chef qui décide quoi faire.
- **Researcher** : Celui qui fouille le web pour trouver des infos.
- **Writer** : Celui qui rédige le rapport proprement.
- **Critic** : Celui qui relit et critique pour améliorer la qualité.

Chacun est expert dans son domaine.
